# 04 · 怎么发、发什么

这一章只把公开权重翻译成创作上的取舍。它不是涨粉配方，也不建议去刷任何一种互动。权重乘的是「这位读者会不会这么做」的预测。组织别人来点链接、来回复，既对不上公式，也很容易变成垃圾信号，走到可见性那一侧。

数字以 [02-scoring-weights.md](02-scoring-weights.md) 为准：主表是 `param.rs` 在 2026-11-02 的镜像。

## 先看预测，再看系数

一条帖在某个读者的 For You 里值多少，大致是：

```text
加权和 = Σ 权重 × 这个读者的预测
```

然后才是偏移、作者衰减、站外折扣、可能的冷启动，以及 VMRanker。所以：

- 复制链接的权重是 20，喜欢是 0.66，并不等于「一个复制抵 30 个喜欢」。只有当模型对**这个人**赋予的两项概率差不多时，系数才会按这个比例进入和。
- 举报是 −234，因为模型认为普通人举报的概率极低。它不是「收齐 468 个喜欢才能抵消 1 个举报」。
- 你自己的粉丝来点赞，只影响「像他们的人」以后被预测成也会点。它不是给这条帖加一个全局常数。

## 正向信号，按公开系数

下面是「如果预测概率同量级，哪一类行为在公式里更重」。连续时长除外，它们的单位不是概率。

| 你希望发生的事 | 权重 | 创作上的意思 |
| --- | --- | --- |
| 有人复制链接，拿到别处去说 | 20 | 公开系数里最高的正向项。值得被单独转发出来的一句、一张图、一个可核对的结果，比「求赞」更贴近这项 |
| 互关的人在原创帖下回复 | 回复 5，再加 15，合计 20 | 只加在互关、且不是回复也不是转帖的帖上。写给认识你的人、能接得上话的原创，和写给陌生人的广播不是同一条公式 |
| 回复、引用 | 各 5 | 留一个能接话的口子。引用比转帖更重（5 对 1） |
| 私信分享 | 5 | 模型如果觉得这个人会丢进某个对话，这项不轻。内容要经得起「发给一个具体的人」 |
| 因此关注作者 | 4 | 把人送到你的主页、并且值得关注，比多一个喜欢重 |
| 系统分享 | 2 | 有，但低于复制链接和私信 |
| 转帖 | 1 | 公开默认只是喜欢的大约 1.5 倍（1 / 0.66），远低于回复和引用 |
| 喜欢 | 0.66 | 在正向概率项里偏轻。用「求点赞」换排序，公式并不支持 |
| 点进帖子之后还停着 | 连续项 0.4 | `ContClickDwellTimeWeight`。点开而且读下去，按预测时长计 |
| 点开、点链接 | 0.3 / 0.2 | 有入口，但入口本身不是终点 |
| 看图、普通停留、点进引用 | 0.05 | 轻 |
| 打开视频 | 0.02 | 很轻。视频质量观看 `VqvWeight`、视频帖 `PostVideoWeight` 公开默认都是 0 |
| 未探索帖 | 0.015 | 默认只在站内（`post_unexplored_include_out_of_network` 在 vm-ranker 为 false，home-mixer 本地也写死 false） |
| 时间线上的停留时长 | 连续项 0.006 | 有，但是按秒乘一个很小的系数。不要把「停留权重 0.05」和「停留时长 0.006」当成同一个旋钮 |

互关的停留加成公开是 0。文档写过它做过实验、没有随回复加成一起铺开。不要按「互关就会把停留也乘上去」来发。

## 负向信号

| 读者可能做的事 | 权重 | 怎么理解 |
| --- | --- | --- |
| 举报 | −234 | 最大的负项。针对的是这个读者会不会举报的预测，不是一张全球计数表 |
| 静音作者 | −58.8 | 比屏蔽的系数更大 |
| 不感兴趣 | −52.272 | param.rs 镜像值。vm-ranker 字面量是 −47.52，见权重文档的分叉表 |
| 屏蔽作者 | −31.2 | 同样是预测，不是「被多少人屏蔽就扣多少」 |
| 划走、没有停留 | −0.02 | 系数小，但是它针对的行为常见。又臭又长、封面和正文对不上，会从这里漏分 |

源码明确不支持另一种传说：找一群人去举报、去屏蔽，就能把一条帖从所有人的时间线里按掉。预测是个性化的；人必须是在 Home 里遇到这条帖，那次行为才进这套系统。

## 结构上的硬约束

这些不是权重，但它们决定帖子有没有资格被打分。

- **48 小时。** 更老的帖在 `AgeFilter` 被丢掉。热度不会把过期帖捞回来。
- **自己的帖**不会出现在自己的 For You。
- **站外的回复和转帖**默认进不了候选。想被不认识的人看到，优先是原创，不是在别人楼下回复。
- **站外原创**如果进了价值模型重算，默认再乘 0.75。站内的回复和转帖也会乘。站内原创不乘。
- **同一作者连发。** 多样性默认开着时，这位作者当次候选里的第 2、第 3 条分数乘 0.625、0.4375，并往 0.25 靠。一次请求里堆很多条，后面的条会被公式自己打折。
- **订阅帖**只留给已经订阅的读者。
- **静音词、屏蔽、静音账号**在打分前就没了，轮不到权重。

## 冷启动能帮到哪一步

默认开着，但很窄：

- 原创，作者粉丝 ≤ 50000，帖龄 ≤ 2 小时（7200 秒），Home 展示还不到 200。
- 抬升目标只有一个槽：大约排到第 16 名那个分数，不是置顶。
- 候选池如果凑不满 16 条非零分，这次不抬。
- 用一个很保守的 Beta 先验（0.75, 49.25）在合格帖里抽，再取真实分更高的那条。它奖励的是「还不确定、但排序分不差」，不是「粉丝多」。

过了 200 次 Home 展示，或过了 2 小时，这条抬升就结束。之后只剩普通的预测分。前两小时里，真正会被模型当成正向证据的，仍是具体的人愿不愿意回复、引用、把链接带出去、读完，而不是空心的曝光本身。

## 不建议做的事

- 不要在文案里索要复制链接、私信或回复来「对冲权重」。那是在优化一个你控制不了的预测，而且集中、重复的诱导更接近垃圾标签要抓的东西。
- 不要用 Blue / Premium 解释排序。公开打分权重里没有这个乘数。
- 不要把 48 小时以前的旧帖拿去「重发冲榜」而不当成一条新帖。年龄过滤看的是这条帖的 id 时间。
- 不要用「解限」「申诉 shadowban」解释一次普通的低曝光。下一章写检测工具能证明什么。

如果四个公开可见性检查都是通过，而曝光仍低：回到这一章。问题在预测到的早期互动、站外折扣、作者衰减和冷启动窗口，不在一个未公开的封禁开关。
