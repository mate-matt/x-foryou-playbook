# 04 · 怎么发、发什么

这一章不讲涨粉玄学，也不教怎么刷数据，纯粹把代码里公开的打分权重，翻译成创作时该怎么做取舍。
必须先理清一个底层逻辑：公式里的权重，乘的是模型对「这位读者会不会做这个动作」的预测概率。找人组团来点链接、刷回复，在公式底层根本对不上号，反而极容易被风控识别成垃圾信号，直接卡死在可见性那一关。

数字以 [02-scoring-weights.md](02-scoring-weights.md) 为准：主表是 `param.rs` 在 2026-11-02 的镜像。

## 先看预测，再看系数

一条帖子在某个读者的 For You 信息流里值多少分，大体上是这么算的：

```text
加权和 = Σ 权重 × 这个读者的预测
```

算出加权和之后，后面还要叠加偏置、作者衰减、站外折扣、可能的冷启动扶持，最后再交由 VMRanker 重排。所以千万别望文生义：

- 复制链接的权重是 20，喜欢是 0.66，但这绝不等于「一次复制能顶 30 个喜欢」。只有当模型预测**这个人**做出这两个动作的概率处在同一量级时，系数才会按这个比例进入总和。
- 举报的权重是 −234，这是因为模型评估普通读者点举报的概率极低。它可不是说「必须收齐 468 个喜欢，才能抵消 1 个举报扣的分」。
- 你自己的粉丝跑来点赞，影响的也只是系统未来对「和他们画像类似的人」的互动预测，并不会给这条帖子凭空加一个全网通用的常数加分。

## 正向信号，按公开系数

下面梳理的是「假设预测概率处在同一量级，哪些行为在公式里权重更重」。注意：连续停留时长除外，它的计量单位是时间，不是概率。

| 你希望发生的事 | 权重 | 创作上的意思 |
| --- | --- | --- |
| 有人复制链接，拿到别处去说 | 20 | 公开系数里权重最高的正向项。一段值得单独发出去的金句、一张高信息量截图，或者一个可核对的结论，都远比在正文里「求点赞」更贴合这项 |
| 互关的人在原创帖下回复 | 回复 5，再加 15，合计 20 | 仅针对互关好友在非回复、非转帖的原创内容下的互动。写给熟人能接得上话的原创，和丢给陌生人的单向广播走的原型公式根本不同 |
| 回复、引用 | 各 5 | 帖子里留个能让人接话的口子。引用的分量明显高于纯转帖（5 对 1） |
| 私信分享 | 5 | 如果模型预测读者会把帖子扔进某个对话里，这个权重相当可观。内容要经得起让人「顺手发给某个具体朋友」的考验 |
| 因此关注作者 | 4 | 能吸引读者点进主页顺手点个关注，价值远大于单纯多拿一个喜欢 |
| 系统分享 | 2 | 算正向信号，但权重明显低于直接复制链接和私信 |
| 转帖 | 1 | 公开默认权重仅为喜欢的约 1.5 倍（1 / 0.66），远落后于回复和引用 |
| 喜欢 | 0.66 | 在所有正向概率项里分量偏轻。指望靠「求点赞」来拉升排序，底层公式并不买账 |
| 点进帖子之后还停着 | 连续项 0.4 | 对应 `ContClickDwellTimeWeight`。点开而且愿意继续读下去，按模型预测的停留时长计分 |
| 点开、点链接 | 0.3 / 0.2 | 能引人点击展开或点外链固然有分，但光有点开动作本身并不是终点 |
| 看图、普通停留、点进引用 | 0.05 | 基础交互，权重很轻 |
| 打开视频 | 0.02 | 非常轻。视频质量观看 `VqvWeight`、视频帖基础分 `PostVideoWeight` 公开默认全是 0 |
| 未探索帖 | 0.015 | 默认只在站内生效（`post_unexplored_include_out_of_network` 在 vm-ranker 为 false，home-mixer 本地也写死 false） |
| 时间线上的停留时长 | 连续项 0.006 | 确实有分，但是按秒乘上一个极小的系数。千万别把「停留动作权重 0.05」和「停留时长连续项 0.006」当成同一个旋钮 |

公开代码里互关读者的停留加成其实是 0。官方文档提到过它只做过实验，并没有随互关回复加成一起全量推开。发帖时别幻想「互关好友多看几秒就会把停留分数乘上去」。

## 负向信号

| 读者可能做的事 | 权重 | 怎么理解 |
| --- | --- | --- |
| 举报 | −234 | 惩罚最大的负向项。它乘的是对这位读者会不会举报的预测概率，而不是全网累加的举报计数表 |
| 静音作者 | −58.8 | 扣分比直接拉黑屏蔽还要重 |
| 不感兴趣 | −52.272 | 这是 param.rs 镜像里的数值；vm-ranker 字面量是 −47.52，具体差异见权重文档的分叉表 |
| 屏蔽作者 | −31.2 | 同样是概率预测，并不是「现实中被多少人拉黑就扣多少分」 |
| 划走、没有停留 | −0.02 | 单次扣分系数看着很小，但划走属于最高频的行为。内容又臭又长、封面和正文对不上，很容易在这里持续漏分 |

源码逻辑明确不支持坊间的另一种传言：找一群人抱团举报、屏蔽，就能把一条帖子彻底从所有人的时间线里按掉。模型打分完全是个性化预测；更关键的是，只有读者是在 Home 信息流里刷到该帖所产生的交互，行为才会被纳入这套系统。

## 结构上的硬约束

这些虽然不是权重项，却直接决定了一条帖子到底有没有资格进入候选池被打分。

- **48 小时：** 超过 48 小时的旧帖会在 `AgeFilter` 中被直接丢弃，再高的互动热度也无法把过期帖重新捞回流里。
- **排除自己：** 自己发的帖子绝不会出现在自己的 For You 推荐流里。
- **站外回复和转帖：** 默认根本进不了候选池。想被陌生人刷到，优先策略永远是发原创，而不是跑到别人的楼下蹭回复。
- **站外原创打折：** 站外原创内容一旦进入价值模型重算，默认会被乘上 0.75 的折扣；站内的回复和转帖同样要乘 0.75，只有站内原创不打折。
- **同一作者连发：** 多样性打散机制默认开启时，同一作者在当次候选里的第 2、第 3 条分数会分别乘上 0.625、0.4375，后续条数更是逼近 0.25。一次请求里连发堆太多条，后面的内容在系统内部就先被狠狠打折了。
- **订阅帖：** 专属订阅内容只向已经订阅的读者展示。
- **静音与屏蔽前置：** 静音词、屏蔽名单、静音账号等规则在进入模型打分之前就会被提前过滤掉，根本轮不到算权重那一阶段。

## 冷启动能帮到哪一步

冷启动扶持机制默认开启，但适用范围卡得很窄：

- 必须是原创帖，作者粉丝 ≤ 50000，帖龄 ≤ 2 小时（7200 秒），且在 Home 信息流里的展示次数还不到 200 次。
- 抬升目标只有一个坑位：大体相当于提到排在第 16 名左右的分数线，并不是直接送上置顶。
- 候选池里如果凑不满 16 条有非零得分的帖子，这次推荐干脆就不抬了。
- 采用极其保守的 Beta 先验（0.75, 49.25）在合格候选里采样，再取真实预估分更高的那条。它奖励的是「数据表现尚不确定、但初筛排序分还不错的新帖」，而不是给「粉丝多」的人锦上添花。

一旦在 Home 信息流累计展示满 200 次，或者发布超过了 2 小时，冷启动的扶持窗口立刻结束，之后全凭普通的模型预测分说话。在前两小时里，真正会被模型当成正向证据的硬通货，依然是具体的读者愿不愿意回复、引用、把链接分享出去以及完整读完，而不是那些虚浮的空心曝光。

## 不建议做的事

- **不要在文案里索要复制链接、私信或回复来「冲权重」：** 这本质上是在妄图优化一个你根本掌控不了的个性化预测；而且集中、重复的诱导话术，极易触发垃圾内容风控的抓取规则。
- **不要用 Blue / Premium 来解释排序：** 公开的推荐打分权重里压根没有这个付费加成系数。
- **不要把超过 48 小时的旧帖拿去「重发冲榜」：** 哪怕改了内容，年龄过滤器认的依然是原帖的 id 时间，必须当作全新的一条帖子重新发布才算数。
- **不要把一次普通的低曝光随口归咎于「被限流」或「申诉 shadowban」：** 下一章会具体讲清楚各类检测工具到底能证明什么。

如果四个公开可见性检查全都顺利通过，而实际曝光依然很低，不妨重新回到这一章的逻辑：问题通常出在模型预测到的早期互动偏弱、站外折扣、同一作者衰减以及错过了冷启动窗口，背后并没有什么未公开的隐形封禁开关。
