# 05 · Shadowban Radar 可信度

研究日期：2026-11-04（Asia/Shanghai）。  
评估对象：[Shadowban Radar](https://shadowbanradar.com/)。  
本章整理了当时对该工具的可靠性评估，并对照 [x-algorithm](https://github.com/xai-org/x-algorithm) 的逻辑，理清「可见性过滤」与「算法排序」的边界。官方方法论页面：<https://shadowbanradar.com/methodology>（页面 Open Graph 标注时间为 2026-11-02）；官方对照页：<https://shadowbanradar.com/x-under-the-hood>。

当前环境里依然没有 Gemini CLI，本文直接根据这份研究整理，原文的所有链接和数字均未改动。

## 执行结论

工具有用，置信度中等。适合当作一份**带日期的公开表面状态快照**，不能当成官方的终审判决。

它一共检查四项指标：搜索建议、搜索、幽灵回复、回复降权。如果拿到的证据不足，它会直接标为 Untestable，而不是胡乱猜测。这也是它比那些张嘴就来「限流分」的工具靠谱的地方。

但必须明确：它**不是**官方执法记录，**不能代表** For You 信息流里的推荐排序质量，**也不是** X 内部的可见性标签。它附带的 ShadowCreed 分数，仅仅是拿公开可见的信号估算出来的账号权重。日常使用中，「回复降权」以及搜索接口的偶发抖动，是导致误报的主要元凶；而那些只限制推荐流、不影响搜索结果的内部标签，以及整体排序分下滑，则是漏报的主要盲区。站点自己统计说大概四成受检账号存在至少一项限制——要搞清楚，这只是「主动跑来检测的用户」里的比例，绝对不等于全站所有账号的真实受限概率。

它和官方的 Under the Hood 是互补关系，谁也替代不了谁。Under the Hood 是给符合条件的登录账号主人看的**上个月**官方执行标签；而 Radar 是在**此时此刻**，站在任何公开账号的角度去查搜索和对话表现。两者的统计时间窗口和测试表面完全不同，就算两边结论打架，也完全可能同时成立。

四项检查全部通过，并不能解释你为什么播放量低。硬可见性（搜索里压根搜不到、回复在对话里彻底蒸发）和软排序（Phoenix 模型打分、互动率、作者多样性降权）根本就是两码事。如果四项测试都绿了，先去复盘内容和排序机制，别整天到处找所谓的「解封玄学」。

## 四项检查

它的数据源自 X 面向所有未登录访问者开放的搜索与对话流，由其背后的第三方数据供应商拉取。整个过程不登录任何账号，不读取系统内部 flag，也不会拿你的浏览量去倒推这四项结果。

| 检查 | 在看什么 | 它自己承认看不到的 |
| --- | --- | --- |
| 搜索建议 | 在搜索框输入 handle 时，下拉联想词还会不会出现。出或者不出，结果只有二元状态 | 不同的用户是否会看到差异化的建议结果；以及「账号还在下拉列表里，但被排到了很靠后的位置」 |
| 搜索 | 账号最近发布的公开推文还能不能搜出来。只看在不在结果里，不测具体排第几 | 个性化搜索的实际排位。遇到接口没有可用响应，或者该账号近期全都在转帖时（X 搜索原本就不返回转帖），结果会标记为 Untestable。但如果是设了隐私保护的锁推号，或者一条帖都没发过，这项会被直接记作搜索限制，而不是 Untestable |
| 幽灵回复 | 顺着回复所在的对话层级以公开视角一路读到底，看你的这条回复到底还在不在 | 嵌套太深读不完的长推文楼，或者发帖人限制了回复范围的楼，都会被标记为 Untestable，不当成失败处理。如果该账号最近压根没回复过别人：这项直接算测完，不算失败，也不计入总分 |
| 回复降权 | 还是同一批回复：按时间线读完整全文时推文明明还在，但在默认推荐视图里却找不到了 | 无法证明平台是否有主观降权意图。一条冷门的回复被旁边高互动量的热评挤下去，从外部表现上看是一模一样的。这是整套测试里最软、主观干扰最大的一项 |

每一项都会附带置信度与抓取时间。只要搜索类的检查能顺利跑通，站点通常会把置信度标为高。

## 分数，以及 Untestable

- 最终得分 = 已经测出明确「通过」或「失败」的检查项中，通过项目所占的比例。四项权重完全均等。
- Untestable **完全不计入总分**。它既不算作失败，也不会折算成半颗星。
- 没有任何一项出现失败：页面提示为 “No shadowban detected”。
- 只要出现一项及以上失败：就会提示 “Shadowban detected”，并列出具体的违规/受限项数。
- 如果四项全因为客观原因测不了：直接显示 “Visibility not measurable”。此时分数留空，而不是打 0 分。

所以，四项全绿拿到的所谓满分，仅仅代表「本次成功执行了的检测项全都过了」。它绝对不等于你账号的可见性处于完全健康状态，更不代表你在 For You 推荐流里一切正常。

这里还有一个极容易被忽略的盲区：如果幽灵回复和回复降权被标记成了 Untestable，或者因为账号近期根本没有回复行为而直接跳过计分，那么这个「No shadowban」**完全无法证明**你的回复功能是正常的。

## ShadowCreed

四项基础检查的计分公式里并不包含 ShadowCreed。它被单独放在了 [tweepcred-score](https://shadowbanradar.com/tweepcred-score) 页面：只有在前面四项都没检出限制时才会展示。它是一个 0–100 的账号「权重」估算值，并不是什么封禁测试。

从我们调研记录下来的模型结构来看，它由 9 项公开维度的信号拼成，拆解为画像分（占 68）与活跃度（占 32）。画像部分主要评估受众质量、是否开通 Premium、关注者/被关注者比例、注册时长以及主页资料是否填写完整；活跃度部分则看近 7 天互动情况、发推规律，以及按账号体量归一化后的互动与浏览表现。它的整体构型借鉴了 2023 年开源的 TweepCred，以及 2026 年开源的 `user-cred-v2`。但要清楚：x-algorithm 里的 `user-cred-v2` 本质是跑在整张关注图和真实互动边上的 PageRank 算法，**绝对不是**网页上测出来的这区区 60 分。站点自己也白纸黑字写明了，这并不是 X 生产环境运行的真实分数。

所以：ShadowCreed 顶多用来当成账号资料完整度和基础活跃度的一套粗糙体检表，它能提供的证据效力，远弱于那四项可以反复验证的二元技术测试。千万不要拿它去论证自己「被限流了」，更别妄图用它来解释复杂的 For You 分发逻辑。

## 误报和漏报

什么时候值得掏出这个工具？当你在**今天**就需要针对**任意公开账号**拿出一个即时判断；或者你想快速排查一个可能因为注册太新、发帖太少而根本进不了 Under the Hood 门槛的新号；又或者你需要快速把「搜索/回复功能在表面上被敲断了」和「单纯内容质量不行没人看」区分开，并打算立一个带日期的快照底稿过两天复测。

误报通常最容易在以下几种场景冒出来：

| 风险 | 原因 |
| --- | --- |
| 回复降权 | 默认视图不给你靠前排，不等于账号遭到了处罚。在一篇非常热闹的推文楼里，没有互动的冷回复本来就会被沉底 |
| 搜索瞬时失败 | 平台的底层接口或者它上游的数据源偶尔网络抖动一下，就会表现得跟搜索被封了一模一样 |
| 观测点单一 | 搜索建议和搜索结果本来就会根据查看者的画像、语言、地理位置动态调整 |
| 锁推、零发帖、刚改过 handle | 传统检测工具通常会弹窗警告这类账号的结果不准。Radar 虽然把其中一部分分流到了 Untestable 或私密处理逻辑中，但边界情况依然容易出 bug |
| 结果存在约 24 小时缓存 | 他们的统计文档明确提到了跨日复用机制，你此时此刻查出来的判决，可能只是昨天保存下来的历史缓存 |

而漏报则更容易在以下情况发生：

| 风险 | 原因 |
| --- | --- |
| 只限制推荐流、不影响搜索 | 没关注你的用户在推荐流里压根看不到你，但去搜你的推文却条条都在。这在机制上非常类似 Under the Hood 里的高召回垃圾标签。这种情况下，Radar 测出来依然是一片全绿 |
| 算法排序分被整体打压 | Phoenix 模型给的交互预估极低。但这种情况下，搜索索引正常，幽灵回复也不会飘红 |
| 回复相关测试根本没跑成 | 见上一节的说明。就算测不了，总分也可能看起来干干净净、全是绿色 |
| 压根不在上述四个公开表面展示的底层限制 | 官方方法论已经把话挑明了：任何只能读取公开界面的外部爬虫工具，对更深层的策略都完全两眼一抹黑 |

目前市面上没有任何经过同行评议的 2025–2026 年客观误报率报告。各路独立的横向对比评测都把「测出问题」当作一次排查的线索起点，而不是盖棺定论的凭据。HiSubway 的官方说明里也直白写着：测试结果不可能保证百分之百准确。

## 和 Under the Hood

官方入口是：[https://x.com/i/jf/under_the_hood](https://x.com/i/jf/under_the_hood)，备用访问路径为 <https://x.com/i/under_the_hood>。其开源实现存放在 x-algorithm 的 `under-the-hood/` 目录下。

Radar 对照页转述了该功能的准入门槛（本手册未对这几个常量做重新验证）：必须是登录后的账号本人；账号注册通常需满 1 年；当月至少发布过 10 条推文；报告产出时间一般不早于当月结束后大约 10 天。它纯粹用来陈列官方打在你身上的标签，既不做任何动态搜索测试，也不会去对比排名。自 2026-09-19 起，文档记录显示他们开始支持展示因法律要求被限流的标签；从 2026-10-30 起，界面已经能直接列出带有具体标签的推文列表。这些均基于该站点对 X 官方推文和公开源码的解读。

| | Under the Hood | Shadowban Radar |
| --- | --- | --- |
| 数据来源 | 直接读取打在账号与推文上的内部标签 | 模拟外部视角请求公开搜索与对话流 |
| 覆盖时间段 | 已经完整过完的自然月 | 发起检测的这一瞬间 |
| 谁有权查看 | 满足门槛的账号本人 | 任何公开 handle 均可查，完全免登录 |
| 是否官方渠道 | 是，官方尽力而为提供的透明度报告 | 否，纯第三方工具 |
| 对齐的表现层 | 内部标签对应的处理策略，例如不再向未关注者推荐 | 搜索建议、搜索结果、幽灵回复、回复降权这四个外显表面 |

排查问题的权威优先级永远是：X 官方站内通知和 Under the Hood 标签高于公开表面的自动化检测，而公开表面检测又高于单纯靠转评赞互动去推导的玄学猜想。第三方工具测的，自始至终都是另一套东西。

## 和 x-algorithm

官方源码 README 写得非常清楚：算法排序决定内容的先后位次，而一条推文到底能不能展示，则交由 `visibility-filtering/` 另行判定。

- 硬过滤分支：`VFFilter` 会直接扔掉标记为 `Drop`、`Tombstone`、`NotEvaluated` 的推文；至于标记为 `Allow`、`Interstitial`、`Avoid`、`Downrank` 的内容，则继续留在候选池里。细节参考 [03-filters-visibility.md](03-filters-visibility.md)。
- 软排序分支：Avoid、Downrank、各种安全遮罩，再叠加 Phoenix 模型对点赞、回复、停留时长、举报概率的打分预估。大部分所谓的「没流量」，实际都死在这个环节。
- Under the Hood 展示的仅仅是一份公开的标签白名单，开源仓库从未声明过这就是生产环境生效的全部标签集合。许多 botmaker 相关的反作弊规则，自始至终都没有公开。

Radar 这四个项目，充其量只能反映出搜索索引和回复表面呈现出来的外部表征。它既不等同于「你的账号在系统底层被打了 DROP 标签」，也绝不意味着「你在 For You 里的排序表现非常健康」。

## 其他同类检测工具

在技术实现路径相同的同类工具里，[shadowban.yuzurisa.com](https://shadowban.yuzurisa.com) 和 [hisubway.online/shadowban](https://hisubway.online/shadowban) 跑的也是这四套检查。HiSubway 的帮助文档直接声明了测试无法做到百分之百精准。至于 Circleboom 这类商业工具，动不动就强制要求绑定授权 X 账号，各项指标的命名五花八门，还存在登录与授权泄露的风险。amishadowbanned、Postory 虽然探测的维度更宽泛，但本质上依然摆脱不了第三方的局限性。Radar 的唯一优势在于方法论文档写得足够透明，并且遇到拿不准的情况会老老实实标 Untestable 而不瞎判。但这也改变不了它依然只是个民间工具的事实。

在官方统计页 [x-shadowban-statistics](https://shadowbanradar.com/x-shadowban-statistics) 上，测出来的受检账号里约有 40%–43% 至少命中了一项限制。一定要清楚，这批样本全都是自己怀疑账号有问题才主动跑去测试的人。绝不能断章取义地把它吹成「X 上有四成的账号都被影子封禁了」。

## @mate_mattt，2026-11-04

实际测试结果页：<https://shadowbanradar.com/r/mate_mattt>

调研留存的快照数据为：**No shadowban detected**，ShadowCreed 给出 **60/100 Solid**。四项检测全部无异常。这里的 60 分纯粹是另一套公开信号的拟合估算，既不代表四项测试拿了满分，更不意味着账号被降权处罚。在同一份快照里，推文的实际浏览量大概占粉丝数的 2.9%。这一数据完全吻合「公开层面的硬可见性一切正常，整体曝光低纯粹由算法排序和冷启动阶段的互动不足导致」的推论，根本不需要去迷信「先找路子解封再发帖」那套说辞。

该数据直接取自当天该页面的抓取快照，并非本手册重新发起扫描的结果，亦非来自 X 官方的背书。

在日常排查中，可以参考如下 SOP：

1. 保持常规每周自测一次；或者在遇到突然完全搜不到推文、回复完全没人理等疑似蒸发的情况时测一次。务必截图并记录测试日期、四项各自的结论以及置信度。
2. 别把 ShadowCreed 测出的 60 分理解为「被平台限流」。它顶多说明你的资料完善度和最近的互动频率比较平庸。
3. 如果账号符合 Under the Hood 的查看资格，每月定期核对一次官方标签名称及其生效范围，拿它和 Radar 的即时表现做交叉对比，不要用单方结论直接否定另一方。
4. 如果 Radar 提示存在限制：先使用完全退出登录的无痕浏览器，对照方法论手动复现；同时检查 X 站内的官方系统通知。随后停止任何疑似 spam 的高频操作，修正发帖习惯，隔天再测。
5. 如果 Radar 测出来全绿但播放量依然低迷：优先审视内容质量、发布时间节点，以及推文能否引发讨论、是否有人愿意在评论区互动或转发外链。别陷入「寻找解封秘籍」的思维陷阱。公开源码的推荐排序打分里压根没有所谓的 Premium 霸王乘数，千万别天真地把氪金开会员当成流量开关。至于 ShadowCreed 会把 Premium 算进它的画像分，那是第三方工具自己的评估模型，别和官方机制混为一谈。
6. 如果你唯一的佐证仅仅是 Radar 的测试页面，切勿在公开场合声称「X 官方确认我被影子封禁了」。
7. 尽量只选用无需登录授权的被动检测工具。如非必要，绝不要把关键的日常运营账号授权给任何索要 OAuth 权限的检测平台。
